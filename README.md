# Job Tracker Frontend

React app connected to the Job Tracker backend API.

## Tech
- React 18 + Vite
- Axios
- Tailwind CSS
- React Router DOM

## How to run
1. Clone the repo
2. Make sure the backend API is running
3. Run:
   ```
   npm install
   npm run dev
   ```
4. Open `http://localhost:5173`

## Themes
☀️ Light · 🌙 Dark · 🌊 Ocean · 🌅 Sunset

Theme is saved in localStorage.

## Pages
- Companies — add and delete companies
- Jobs — add jobs linked to a company
- Applications — track application status per job
